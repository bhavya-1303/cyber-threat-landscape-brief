# Cyber Threat Landscape Brief

**Project:** InternCircle — Project 01  
**Topic:** Cyber Threat Landscape and Cybersecurity Awareness  
**Audience:** College Students

## Overview
This project explains five common cybersecurity threats and practical steps students can take to stay safe online.

## Threats Covered
1. Phishing Attacks
2. Weak or Reused Passwords
3. Ransomware
4. Public Wi-Fi Risks
5. Fake or Malicious Mobile Applications

## Project Deliverables
- Cyber Threat Landscape Brief (PDF)
- Cybersecurity Awareness Poster

## Key Message
Think before you click, verify before you trust, and stay safe online.

## Sources
The report references cybersecurity guidance from CERT-In, CISA, and Verizon's Data Breach Investigations Report.
